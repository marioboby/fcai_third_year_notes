# Autoregressive Models - **<font color="#00b050">By: Youssef Amgad</font>**

### Direct Method

The simplest way to generate an image is to predict it pixel-by-pixel using conditional probability.

#### 1. Setup & Preprocessing

Assume 3 binarized training images of dimension $2 \times 2$:

  

$$I_{1}=\begin{bmatrix}0 & 0\\ 1 & 1\end{bmatrix}, \quad I_{2}=\begin{bmatrix}0 & 1\\ 1 & 0\end{bmatrix}, \quad I_{3}=\begin{bmatrix}1 & 1\\ 0 & 0\end{bmatrix}$$

  

Flatten into 1D arrays of binary pixels $(x_1, x_2, x_3, x_4)$:

  

- $I_{1} = [0, 0, 1, 1]$
    
      
    
- $I_{2} = [0, 1, 1, 0]$
    
      
    
- $I_{3} = [1, 1, 0, 0]$
    
      
    

Decomposition by the probability chain rule:

  

$$P(x_1, x_2, x_3, x_4) = P(x_1) \cdot P(x_2 \mid x_1) \cdot P(x_3 \mid x_1, x_2) \cdot P(x_4 \mid x_1, x_2, x_3)$$

  

#### 2. Conditional Probability Calculations

Extracted directly by frequency matching across the 3 training samples:

> [!Note] هنعمل ايه بالضبط
> اللي هيحصل هنا بالضبط اني هشوف قيمة كل بيكسل بالترتيب في كل الصور و احسب احتمالية كل واحدة، بحيث هبدأ بأول بيكسل و اشوف احتمال قيمها المختلفة "اللي هو 0 و 1" علي مستوى كل الصور، بعدها أول ما أبدأ اخش في ال Conditional من تاني بيكسل فما بعدها، اشوف كل ال Combinations للبيكسلات اللي قبلي الموجودة في الصور بتاعتي، و أبدأ احسب احتمال ظهورهم مع كل قيم البيكسل اللي أنا واقف عليها
  

- Pixel 1 ($x_1$):
    
      
    - $P(x_1 = 1) = \frac{1}{3}$ (only $I_3$ starts with 1)
        
          
        
    - $P(x_1 = 0) = \frac{2}{3}$ ($I_1$ and $I_2$ start with 0)
        
          
        
- Pixel 2 ($x_2$):
    
      
    - If $x_1 = 1$: $P(x_2 = 1 \mid x_1 = 1) = 1$ (from $I_3$)
        
          
        
    - If $x_1 = 0$: $P(x_2 = 1 \mid x_1 = 0) = \frac{1}{2}$ (from $I_2$), $P(x_2 = 0 \mid x_1 = 0) = \frac{1}{2}$ (from $I_1$)
        
          
        



- Pixel 3 ($x_3$):
    
      
    - If $x_1 = 1, x_2 = 1$: $P(x_3 = 0 \mid 1, 1) = 1$ (from $I_3$)
        
          
        
    - If $x_1 = 0, x_2 = 0$: $P(x_3 = 1 \mid 0, 0) = 1$ (from $I_1$)
        
          
        
    - If $x_1 = 0, x_2 = 1$: $P(x_3 = 1 \mid 0, 1) = 1$ (from $I_2$)
        
          

> هنا مثلا، شوفنا الأول كل ال Combinations للبيكسلات اللي قبل البيكسل التالتة الموجودة في الصور عندي (اللي هما تلت احتمالات بس)، و احسب بقي احتمالية ظهورهم مع كل قيم البيكسل اللي أنا واقف عليها "في الحالة دي، المقام بيبقي عدد الصور اللي فيها Combinations البيكسلات اللي قبلي" 

- Pixel 4 ($x_4$):
    
      
    - If $x_1 = 1, x_2 = 1, x_3 = 0$: $P(x_4 = 0) = 1$ (from $I_3$)
        
          
        
    - If $x_1 = 0, x_2 = 0, x_3 = 1$: $P(x_4 = 1) = 1$ (from $I_1$)
        
          
        
    - If $x_1 = 0, x_2 = 1, x_3 = 1$: $P(x_4 = 0) = 1$ (from $I_2$)
        
          
        

#### 3. Sampling 5 New Images

Because every conditional branch collapses to a probability of 1 after branching, sampling strictly reproduces training instances:

  

1. Sample $x_1 = 0 \implies$ sample $x_2 \mid 0 \to 1 \implies x_3, x_4$ forced to $1, 0 \implies [0, 1, 1, 0]$ (Matches $I_2$)
    
      
    
2. Sample $x_1 = 0 \implies$ sample $x_2 \mid 0 \to 0 \implies x_3, x_4$ forced to $1, 1 \implies [0, 0, 1, 1]$ (Matches $I_1$)
    
      
    
3. Sample $x_1 = 1 \implies x_2, x_3, x_4$ forced to $1, 0, 0 \implies [1, 1, 0, 0]$ (Matches $I_3$)
    
      
    
4. Sample $x_1 = 0 \implies$ sample $x_2 \mid 0 \to 1 \implies [0, 1, 1, 0]$ (Matches $I_2$)
    
      
    
5. Sample $x_1 = 1 \implies [1, 1, 0, 0]$ (Matches $I_3$)
    
      
    

### Problems with the Direct Method 

1. <font color="#ff0000">Curse of Dimensionality</font>: Storing all conditional probabilities requires an exponentially large lookup table ($𝑂(2^𝑁)$ for $N$ binary pixels). For a tiny 28x28 image, you need 2784 table entries, which is computationally impossible. 
   
2. <font color="#ff0000">Zero Frequency / Overfitting</font>: If a specific pixel combination never appeared in the training set (e.g., $𝑥_1 = 1,𝑥_2 = 0$), its probability is exactly 0. The model can never generate novel combinations; it only memorizes and repeats the training data.

### Fully Visible Sigmoid Belief Network (FVSBN): Numerical Example (1 Iteration)

To fix the exponential table size of the direct method, FVSBN replaces the lookup table with Logistic Regression. Instead of tracking every exact sequence, it learns weights (𝛼) that represent how much each previous pixel influences the current one. 

#### 1. Setup & Formula

FVSBN models conditional probabilities via logistic regression:

  

$$P(x_i = 1 \mid x_{<i}) = \sigma\left(\alpha_0^{(i)} + \sum_{j < i} \alpha_j^{(i)} x_j\right)$$

  

Task: Predict pixel $x_2$ given pixel $x_1$:

  

$$P(x_2 = 1 \mid x_1) = \sigma(\alpha_0 + \alpha_1 x_1)$$

  recall our 3 images:
  $$I_{1}=\begin{bmatrix}0 & 0\\ 1 & 1\end{bmatrix}, \quad I_{2}=\begin{bmatrix}0 & 1\\ 1 & 0\end{bmatrix}, \quad I_{3}=\begin{bmatrix}1 & 1\\ 0 & 0\end{bmatrix}$$

- **Initial weights**: $\alpha_0 = 0$, $\alpha_1 = 0.5$
    
      
    
- **Learning rate**: $\eta = 1.0$
    
      
    
- **Training pairs $(x_1 \to x_2)$**:
    
      
    - From $I_1$: $x_1 = 0 \to \text{Target } y = 0$
        
          
        
    - From $I_2$: $x_1 = 0 \to \text{Target } y = 1$
        
          
        
    - From $I_3$: $x_1 = 1 \to \text{Target } y = 1$
        
          
        

#### 2. Forward Pass (Predictions)

- For $I_1\ (x_1 = 0)$:
    
      
    
    $$\hat{y}_1 = \sigma(0 + 0.5 \cdot 0) = \sigma(0) = 0.5$$
    
      
    
- For $I_2\ (x_1 = 0)$:
    
      
    
    $$\hat{y}_2 = \sigma(0 + 0.5 \cdot 0) = \sigma(0) = 0.5$$
    
      
    
- For $I_3\ (x_1 = 1)$:
    
      
    
    $$\hat{y}_3 = \sigma(0 + 0.5 \cdot 1) = \sigma(0.5) \approx 0.6225$$
    
      
    

#### 3. Loss Calculation (Mean Squared Error)

$$\text{MSE} = \frac{1}{3}\sum_{k=1}^{3} (\hat{y}_k - y_k)^2$$

  

- $\text{Error}_1 = (0.5 - 0)^2 = 0.25$
    
      
    
- $\text{Error}_2 = (0.5 - 1)^2 = (-0.5)^2 = 0.25$
    
      
    
- $\text{Error}_3 = (0.6225 - 1)^2 = (-0.3775)^2 \approx 0.1425$
    
      
    
- $\text{Total MSE} = \frac{0.25 + 0.25 + 0.1425}{3} = \frac{0.6425}{3} \approx 0.2142$
    
      
    
احنا حلينا مع الدكتور لغاية هنا، باقي الخطوات ممكن تعرفها زيادة بس هي مجرد حسبة gradients و chain rule عادي
#### 4. Gradient Calculation (MSE with Sigmoid Derivative)

Derivative of sigmoid is $\hat{y}(1 - \hat{y})$:

  

$$\frac{\partial L}{\partial w} = \frac{2}{N}\sum (\hat{y} - y) \cdot [\hat{y}(1 - \hat{y})] \cdot x_{\text{input}}$$

  

Per-sample delta terms $(\hat{y} - y) \cdot [\hat{y}(1 - \hat{y})]$:

  

- $I_1: (0.5 - 0) \cdot [0.5(1 - 0.5)] = 0.5 \cdot 0.25 = 0.125$
    
      
    
- $I_2: (0.5 - 1) \cdot [0.5(1 - 0.5)] = -0.5 \cdot 0.25 = -0.125$
    
      
    
- $I_3: (0.6225 - 1) \cdot [0.6225(1 - 0.6225)] = -0.3775 \cdot 0.235 = -0.0887$
    
      
    

**Gradient for bias $\alpha_0$** ($x_{\text{input}} = 1$):

  

$$\frac{\partial L}{\partial \alpha_0} = \frac{2}{3}(0.125 - 0.125 - 0.0887) = \frac{2}{3}(-0.0887) = -0.0591$$

  

**Gradient for weight $\alpha_1$** ($x_{\text{input}} = x_1$):

  

$$\frac{\partial L}{\partial \alpha_1} = \frac{2}{3}[(0.125 \cdot 0) + (-0.125 \cdot 0) + (-0.0887 \cdot 1)] = \frac{2}{3}(-0.0887) = -0.0591$$

  

#### 5. Weight Update (Gradient Descent)

With $\eta = 1.0$:

  

$$\alpha_0^{(\text{new})} = \alpha_0 - \eta\left(\frac{\partial L}{\partial \alpha_0}\right) = 0 - (1.0 \cdot -0.0591) = 0.0591$$

  

$$\alpha_1^{(\text{new})} = \alpha_1 - \eta\left(\frac{\partial L}{\partial \alpha_1}\right) = 0.5 - (1.0 \cdot -0.0591) = 0.5591$$

### The Problem with FVSBN

While FVSBN solves the $𝑂(2^𝑁)$ memory issue of the direct method, it introduces an $𝑂(𝑁^2)$ parameter issue (each block has its own model, $\frac{n*(n+1)}{2}$). Every conditional probability $P(X_i|X<i)$ requires its own independent set of weights. There is no parameter sharing. For a modern image size, calculating independent logistic regressions for every single pixel interaction leads to massive overfitting and painfully slow training times.

# Autoencoders

### Sparse Autoencoder (SAE): Numerical Example

#### 1. Setup & Formula

A Sparse Autoencoder regularizes activations $a_j \in (0, 1)$ across a dataset or batch of size $M$ by penalizing the empirical average activation $\hat{\rho}_j$ when it diverges from a target sparsity parameter $\rho$:

  

$$\hat{\rho}_j = \frac{1}{M}\sum_{m=1}^{M} a_j(x^{(m)})$$

The penalty is calculated using the Bernoulli Kullback-Leibler (KL) divergence summed over all $s$ hidden units:

  

$$\mathcal{L}_\rho = \sum_{j=1}^{s} \text{KL}(\rho \parallel \hat{\rho}_j) = \sum_{j=1}^{s} \left(\rho \log\frac{\rho}{\hat{\rho}_j} + (1 - \rho)\log\frac{1 - \rho}{1 - \hat{\rho}_j}\right)$$

- **Batch size**: $M = 100$
    
      
    
- **Target sparsity**: $\rho = 0.10$ ($10\%$)
    
      
    
- **Hidden layer size**: $s = 2$ neurons
    
      
    
- **Regularization weight**: $\lambda$
    
      
    

#### 2. Forward Pass & Empirical Activation Rates

Pass all 100 samples through the encoder to obtain the average activation for each hidden neuron:

  

- For Neuron 1 ($j=1$):
    
      
    
    $$\hat{\rho}_1 = \frac{1}{100}\sum_{i=1}^{100} a_1(x^{(i)}) = 0.30$$
    
    _(Neuron 1 is firing at $3\times$ the target rate $\rho = 0.10$)_
    
      
    
- For Neuron 2 ($j=2$):
    
      
    
    $$\hat{\rho}_2 = \frac{1}{100}\sum_{i=1}^{100} a_2(x^{(i)}) = 0.08$$
    
    _(Neuron 2 is firing very close to target rate $\rho = 0.10$)_
    
      
    

#### 3. Sparsity Penalty Calculation (KL Divergence)

Using natural logarithms:

  

- **Neuron 1 Penalty ($\text{KL}_1$):**
    
      
    
    $$\text{KL}(\rho \parallel \hat{\rho}_1) = 0.1 \log\left(\frac{0.1}{0.3}\right) + 0.9 \log\left(\frac{0.9}{0.7}\right)$$
    
    $$\text{KL}_1 = 0.1 \log(0.3333) + 0.9 \log(1.2857) = 0.1(-0.4771) + 0.9(0.1091) = 0.05048$$
    
- **Neuron 2 Penalty ($\text{KL}_2$):**
    
      
    
    $$\text{KL}(\rho \parallel \hat{\rho}_2) = 0.1 \log\left(\frac{0.1}{0.08}\right) + 0.9 \log\left(\frac{0.9}{0.92}\right)$$
    
    $$\text{KL}_2 = 0.1 \log(1.25) + 0.9 \log(0.97826) = 0.1(0.0969) + 0.9(-0.0095) \approx 0.0011$$
    
- **Total Sparsity Loss ($\mathcal{L}_\rho$):**
    
      
    
    $$\mathcal{L}_\rho = \text{KL}_1 + \text{KL}_2 = 0.05048 + 0.0011 = 0.05158$$
    

#### 4. Decoder Pass & Reconstruction Error (MSE)

For a single sample with hidden activations $h = [0.8, 0.2]$:

  

- **Original vector ($x$):** $x = [1, 0, 1, 0]$ ($n = 4$)
    
      
    
- **Reconstructed vector ($\hat{x}$):** $\hat{x} = [0.9, 0.1, 0.8, 0.2]$
    
      
    

Calculate the Mean Squared Error across dimensions:

  

$$\mathcal{L}_{\text{MSE}} = \frac{1}{4} \sum_{i=1}^{4} (x_i - \hat{x}_i)^2$$

$$\mathcal{L}_{\text{MSE}} = \frac{(1 - 0.9)^2 + (0 - 0.1)^2 + (1 - 0.8)^2 + (0 - 0.2)^2}{4} = \frac{0.01 + 0.01 + 0.04 + 0.04}{4} = \frac{0.10}{4} = 0.025$$

#### 5. Total Loss Calculation

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{MSE}} + \lambda\mathcal{L}_\rho = 0.025 + 0.05158\lambda$$

### Contractive Autoencoder (CAE): Numerical Example

#### 1. Setup & Formula

A Contractive Autoencoder adds an explicit penalty directly to the objective function using the squared Frobenius norm of the encoder's Jacobian matrix $J_f(x)$:

  

$$\Vert{}J_f(x)\Vert{}_F^2 = \sum_{i,j} \left(\frac{\partial h_j(x)}{\partial x_i}\right)^2$$

$$\mathcal{J}_{\text{CAE}}(\theta) = \sum_{x \in \mathcal{D}_n} \left(L(x, g(f(x))) + \lambda \Vert{}J_f(x)\Vert{}_F^2\right)$$

- **Input vector ($x$):**
    
      
    
    $$x = \begin{bmatrix} x_1 \\ x_2 \end{bmatrix} = \begin{bmatrix} 1 \\ 2 \end{bmatrix}$$
    
- **Encoder functions ($y = f(x)$):**
    
      
    
    $$y_1 = 2x_1 + x_2$$
    
    $$y_2 = x_1 + 3x_2$$
    

#### 2. Forward Pass (Outputs)

Evaluate encoder activations at the input point $(1, 2)$:

  

- $y_1 = 2(1) + (2) = 4$
    
      
    
- $y_2 = (1) + 3(2) = 7$
    
      
    
- **Output vector ($y$):**
    
      
    
    $$y = \begin{bmatrix} y_1 \\ y_2 \end{bmatrix} = \begin{bmatrix} 4 \\ 7 \end{bmatrix}$$
    

#### 3. Jacobian Partial Derivatives

Compute first-order derivatives for each output dimension with respect to each input dimension:

  

- For $y_1 = 2x_1 + x_2$:
    
      
    - $\frac{\partial y_1}{\partial x_1} = 2$
        
          
        
    - $\frac{\partial y_1}{\partial x_2} = 1$
        
          
        
- For $y_2 = x_1 + 3x_2$:
    
      
    - $\frac{\partial y_2}{\partial x_1} = 1$
        
          
        
    - $\frac{\partial y_2}{\partial x_2} = 3$
        
          
        

Construct the full Jacobian matrix:

  

$$J_f(x) = \begin{bmatrix} \frac{\partial y_1}{\partial x_1} & \frac{\partial y_1}{\partial x_2} \\ \frac{\partial y_2}{\partial x_1} & \frac{\partial y_2}{\partial x_2} \end{bmatrix} = \begin{bmatrix} 2 & 1 \\ 1 & 3 \end{bmatrix}$$

#### 4. Contractive Penalty Calculation (Squared Frobenius Norm)

Sum the squares of all elements in the Jacobian matrix:

$$\Vert{}J_f(x)\Vert{}_F^2 = \left(\frac{\partial y_1}{\partial x_1}\right)^2 + \left(\frac{\partial y_1}{\partial x_2}\right)^2 + \left(\frac{\partial y_2}{\partial x_1}\right)^2 + \left(\frac{\partial y_2}{\partial x_2}\right)^2$$

$$\Vert{}J_f(x)\Vert{}_F^2 = 2^2 + 1^2 + 1^2 + 3^2 = 4 + 1 + 1 + 9 = 15$$

#### 5. Total Loss

$$\mathcal{J}_{\text{CAE}}(\theta) = \sum_{x \in \mathcal{D}_n} \left(L(x, g(f(x))) + \lambda 15 \right)$$

### Variational Autoencoder (VAE)

### 1. Setup & Formula

A Variational Autoencoder maps input data into a parameterized latent distribution $q_\phi(z \mid x) = \mathcal{N}(\mu, \sigma^2)$ characterized by predicted mean ($\mu$) and standard deviation ($\sigma$) vectors.

  

- **Latent Dimension:** $D = 2$ neurons ($z \in \mathbb{R}^2$)
    
      
    
- **Reparameterization Trick:** Ensures differentiability by decoupling stochasticity:
    
      
    
    $$z = \mu + \sigma \odot \epsilon, \quad \text{where } \epsilon \sim \mathcal{N}(0, I)$$
    
- **Reconstruction Loss (MSE, averaged over data features $n=2$):**
    
      
    
    $$\mathcal{L}_{\text{rec}} = \frac{1}{n} \sum_{i=1}^{n} (x_i - \hat{x}_i)^2$$
    
- **Latent Regularization (Averaged KL Divergence to Standard Normal $\mathcal{N}(0, I)$):**
    
      
    
    $$\mathcal{L}_{\text{KL}} = \frac{1}{D} D_{\text{KL}}\left(\mathcal{N}(\mu, \sigma^2) \,\parallel\, \mathcal{N}(0, I)\right) = -\frac{1}{2D} \sum_{j=1}^{D} \left(1 + \ln(\sigma_j^2) - \mu_j^2 - \sigma_j^2\right)$$
    
- **Total Loss (per sample):**
    
      
    
    $$\mathcal{L} = \mathcal{L}_{\text{rec}} + \beta \mathcal{L}_{\text{KL}}$$
    
- **Batch Total Loss ($B = 2$):**
    
      
    
    $$\mathcal{L}_{\text{batch}} = \frac{1}{B} \sum_{k=1}^{B} \mathcal{L}_k$$
    

### 2. Sample 1 ($I_1$) Walkthrough

**Input & Encoder Output:**

  

- Input Vector ($x^{(1)}$): $x = [0, 1]$
    
      
    
- Predicted Distribution Parameters:
    
      
    
    $$\mu_1 = 0.2, \quad \mu_2 = -0.1$$
    
    $$\sigma_1 = 0.25, \quad \sigma_2 = 0.5$$
    

**Reparameterization Trick (Latent Sampling):** Draw random noise $\epsilon = [1.0, -0.8]$:

  

- $z_1 = \mu_1 + \sigma_1 \epsilon_1 = 0.2 + (0.25)(1.0) = 0.45$
    
      
    
- $z_2 = \mu_2 + \sigma_2 \epsilon_2 = -0.1 + (0.5)(-0.8) = -0.50$
    
      
    
- Latent Vector: $z = [0.45, -0.50]$
    
      
    

**Decoder Pass (Reconstruction):**

  

- Reconstructed output: $\hat{x}^{(1)} = [0.269, 0.622]$
    
      
    

**Reconstruction Loss ($\mathcal{L}_{\text{rec}}^{(1)}$):**

  

$$\mathcal{L}_{\text{rec}}^{(1)} = \frac{(0 - 0.269)^2 + (1 - 0.622)^2}{2} = \frac{0.0724 + 0.1429}{2} = \frac{0.2153}{2} \approx 0.1076$$

**Averaged KL Divergence Loss ($\mathcal{L}_{\text{KL}}^{(1)}$):** Compute dimension-wise components:

  

- **Dimension 1:**
    
      
    
    $$\text{KL}_{11} = -\frac{1}{2} \left(1 + \ln(0.25^2) - 0.2^2 - 0.25^2\right) = -\frac{1}{2}(1 - 2.7726 - 0.04 - 0.0625) \approx 0.9375$$
    
- **Dimension 2:**
    
      
    
    $$\text{KL}_{12} = -\frac{1}{2} \left(1 + \ln(0.5^2) - (-0.1)^2 - 0.5^2\right) = -\frac{1}{2}(1 - 1.3863 - 0.01 - 0.25) \approx 0.3231$$
    
- **Averaged KL for $I_1$ ($D = 2$):**
    
      
    
    $$\mathcal{L}_{\text{KL}}^{(1)} = \frac{\text{KL}_{11} + \text{KL}_{12}}{2} = \frac{0.9375 + 0.3231}{2} = \frac{1.2606}{2} \approx 0.6303$$
    

### 3. Sample 2 ($I_2$) Walkthrough

**Input & Encoder Output:**

  

- Input Vector ($x^{(2)}$): $x = [1, 0]$
    
      
    
- Predicted Distribution Parameters:
    
      
    
    $$\mu_1 = 0.2, \quad \mu_2 = 0.3$$
    
    $$\sigma_1 = 0.8, \quad \sigma_2 = 0.5$$
    

**Reparameterization Trick (Latent Sampling):** Draw random noise $\epsilon = [-1.0, 1.0]$:

  

- $z_1 = \mu_1 + \sigma_1 \epsilon_1 = 0.2 + (0.8)(-1.0) = -0.60$
    
      
    
- $z_2 = \mu_2 + \sigma_2 \epsilon_2 = 0.3 + (0.5)(1.0) = 0.80$
    
      
    
- Latent Vector: $z = [-0.60, 0.80]$
    
      
    

**Decoder Pass (Reconstruction):**

  

- Reconstructed output: $\hat{x}^{(2)} = [0.775, 0.378]$
    
      
    

**Reconstruction Loss ($\mathcal{L}_{\text{rec}}^{(2)}$):**

  

$$\mathcal{L}_{\text{rec}}^{(2)} = \frac{(1 - 0.775)^2 + (0 - 0.378)^2}{2} = \frac{0.0506 + 0.1429}{2} = \frac{0.1935}{2} \approx 0.0968$$

**Averaged KL Divergence Loss ($\mathcal{L}_{\text{KL}}^{(2)}$):** Compute dimension-wise components:

  

- **Dimension 1:**
    
      
    
    $$\text{KL}_{21} = -\frac{1}{2} \left(1 + \ln(0.8^2) - 0.2^2 - 0.8^2\right) = -\frac{1}{2}(1 - 0.4463 - 0.04 - 0.64) \approx 0.0631$$
    
- **Dimension 2:**
    
      
    
    $$\text{KL}_{22} = -\frac{1}{2} \left(1 + \ln(0.5^2) - 0.3^2 - 0.5^2\right) = -\frac{1}{2}(1 - 1.3863 - 0.09 - 0.25) \approx 0.3631$$
    
- **Averaged KL for $I_2$ ($D = 2$):**
    
      
    
    $$\mathcal{L}_{\text{KL}}^{(2)} = \frac{\text{KL}_{21} + \text{KL}_{22}}{2} = \frac{0.0631 + 0.3631}{2} = \frac{0.4262}{2} \approx 0.2131$$
    

### 4. Total Loss Calculation (Weighted by $\beta = 0.5$)

Combining reconstruction loss and averaged latent regularizations:

  

- **Total Loss for Sample 1 ($I_1$):**
    
      
    
    $$\mathcal{L}_1 = \mathcal{L}_{\text{rec}}^{(1)} + \beta \mathcal{L}_{\text{KL}}^{(1)} = 0.1076 + 0.5(0.6303) = 0.1076 + 0.3152 = 0.4228$$
    
- **Total Loss for Sample 2 ($I_2$):**
    
      
    
    $$\mathcal{L}_2 = \mathcal{L}_{\text{rec}}^{(2)} + \beta \mathcal{L}_{\text{KL}}^{(2)} = 0.0968 + 0.5(0.2131) = 0.0968 + 0.1066 = 0.2034$$
    
- **Batch Average Total Loss:**
    
      
    
    $$\mathcal{L}_{\text{batch}} = \frac{\mathcal{L}_1 + \mathcal{L}_2}{2} = \frac{0.4228 + 0.2034}{2} \approx 0.3131$$
    

### 5. Image Generation via Decoder Sampling

To generate a completely novel sample, bypass the encoder entirely:

  

1. Sample a point directly from the standard normal latent prior: $z_{\text{gen}} \sim \mathcal{N}(0, I_2)$.
    
      
    
2. Pass $z_{\text{gen}}$ into the decoder network $g(z)$ to synthesize a new output vector $\hat{x}_{\text{gen}}$.

# GANs

  

## Task 1: GAN Forward Pass & Loss Calculation

### Problem Setup & Network Parameters

- **Input Noise Vector ($z$):**
    
      
    
    $$z = \begin{bmatrix} 1 \\ 1 \end{bmatrix}$$
    
- **Real Image Vector ($x_{\text{real}}$):**

## Task 2: Essay Questions & Neural Network Forward Pass

### Question 1: VAEs vs. GANs

|**Feature**|**Variational Autoencoders (VAEs)**|**Vanilla GANs**|
|---|---|---|
|**Architecture**|**Encoder–Decoder** network|**Generator–Discriminator** adversarial pair|
|**Latent Mapping**|**Bidirectional** ($x \rightarrow z$ via Encoder, $z \rightarrow x$ via Decoder)|**Unidirectional** ($z \rightarrow x$ only; no built-in encoder)|
|**Training Objective**|Maximizes the Evidence Lower Bound (**ELBO**): Reconstruction Loss + KL Divergence|**Minimax game** (Nash equilibrium between $G$ and $D$)|
|**Output Quality**|Smooth, often **blurry** (due to pixel-wise MSE/BCE averaging)|**Sharp, realistic**, and high-frequency detailed|
|**Training Stability**|Stable, well-behaved convergence|Unstable (prone to **mode collapse** and vanishing gradients)|

### Question 2: When to Use BiGAN (Bidirectional GAN) vs. Normal GAN

Use a **BiGAN** instead of a standard GAN when the task requires **mapping real data back into the latent space** ($x \rightarrow z$) in addition to generating samples ($z \rightarrow x$). Because a vanilla GAN lacks an encoder, it cannot infer the latent representation of a given real input.

  

**Key Use Cases:**

  

1. **Unsupervised Feature Learning:** Extracting rich, semantic latent representations from unlabeled datasets to use in downstream tasks (e.g., classification).
    
      
    
2. **Anomaly Detection:** Encoding a test sample $x$ into $z = E(x)$, reconstructing $\hat{x} = G(E(x))$, and measuring the reconstruction/discriminator discrepancy—anomalies fail to reconstruct accurately.
    
      
    
3. **Semantic Image Editing:** Projecting a real image into its latent code $z$, modifying specific attributes in latent space (e.g., expression, lighting), and decoding it back into a realistic edited image.
