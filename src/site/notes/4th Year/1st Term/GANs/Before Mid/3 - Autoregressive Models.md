## Stanford CS236: Deep Generative Models I — Lecture 3
  

> [!Abstract]
> 
> Autoregressive models provide a general way to construct generative models by applying the chain rule of probability to decompose a joint distribution into a product of conditional distributions. Each conditional can then be modeled using familiar predictive machinery such as logistic regression, neural networks, or recurrent neural networks (RNNs).
> 
>   
> 
> The lecture develops this idea from simple logistic-regression autoregressive models through neural autoregressive density estimation, weight sharing and masking, and finally RNN-based autoregressive models. The central trade-off is that autoregressive models make probability evaluation and sampling tractable, but generation remains inherently sequential, creating an important computational bottleneck.

  

## 1. Generative Modeling: The Big Picture

Before discussing autoregressive models, the lecture reviews the general recipe for building a generative model.

  

### 1.1 Start with Data

We assume that our training data consists of samples from some unknown probability distribution:

  

$$x \sim p_{\text{data}}(x)$$

More precisely, the training examples are assumed to be IID (Independent and Identically Distributed):

  

- **Independent:** one training example does not affect another.
    
      
    
- **Identically distributed:** all examples come from the same underlying distribution.
    
      
    

The important difficulty is that we do not know the actual data distribution; we only have access to samples from it.

  

> **Professor's point:** We cannot generally ask, _"What is the probability of this image under the real-world data distribution?"_ because the true distribution is unknown. We only observe examples generated by it.
> 
>   

### 1.2 Define a Model Family

We construct a family of probability distributions:

  

$$p_\theta(x)$$

where:

  

- $x$ is the data.
    
      
    
- $\theta$ represents the model parameters.
    
      
    

The model family is intended to contain distributions capable of approximating the unknown data distribution. In this course, $\theta$ will generally correspond to the parameters of a neural network (whereas previously, parameters might have been conditional probability tables or Bayesian networks).

  

### 1.3 Compare Model Distribution and Data Distribution

We need some measure of how close $p_\theta(x)$ is to $p_{\text{data}}(x)$. The general goal is:

  

$$\arg\min_\theta D(p_{\text{data}} \parallel p_\theta)$$

for some appropriate notion of divergence or discrepancy. The important complication is:

  

- We know the model $p_\theta$ and can evaluate quantities involving it.
    
      
    
- We can sample from $p_{\text{data}}$.
    
      
    
- **We cannot directly evaluate $p_{\text{data}}(x)$.**
    
      
    

## 2. Why Do We Care About Probability?

A generative model that provides probabilities is useful for several reasons:

  

### 2.1 Sampling

If we have a probability distribution $p_\theta(x)$, we would like to be able to sample:

  

$$x \sim p_\theta(x)$$

This allows the model to generate new data (e.g., training a model on handwritten digits to generate new synthetic digits).

  

### 2.2 Maximum Likelihood Training

If we can evaluate $p_\theta(x)$, then we can use Maximum Likelihood Estimation (MLE). Given training data $\mathcal{D} = \{x^{(1)}, x^{(2)}, \dots, x^{(N)}\}$, we seek parameters that maximize the product:

  

$$\prod_{n=1}^{N} p_\theta(x^{(n)})$$

or, more conveniently, the log-likelihood:

  

$$\sum_{n=1}^{N} \log p_\theta(x^{(n)})$$

> **Key idea:** If the model assigns high probability to the observed training examples, then the model is being encouraged to resemble the data distribution.
> 
>   

### 2.3 Anomaly Detection

A generative model can answer: _"How likely is this input according to the distribution I learned?"_ If an observation receives unusually low likelihood ($p_\theta(x) \ll 1$), it may be treated as an anomaly.

  

### 2.4 Adversarial Examples

The professor connects this idea to adversarial examples. An adversarial input may differ from the natural data distribution; therefore, in principle, a good generative model could detect that the input is unusual and assign it a lower likelihood as a warning. _(Note: The lecture presents this as a potential application, not as a guarantee.)_

  

## 3. The Fundamental Idea: The Chain Rule

The central mathematical tool behind autoregressive models is the Chain Rule of Probability.

  

### 3.1 Factorizing a Joint Distribution

Suppose we have four random variables $X_1, X_2, X_3, X_4$. The chain rule allows us to write:

  

$$p(x_1, x_2, x_3, x_4) = p(x_1) \, p(x_2 \mid x_1) \, p(x_3 \mid x_1, x_2) \, p(x_4 \mid x_1, x_2, x_3)$$

More generally, for $n$ variables:

  

$$p(x_1, \ldots, x_n) = \prod_{i=1}^{n} p(x_i \mid x_1, \ldots, x_{i-1}) = \prod_{i=1}^{n} p(x_i \mid x_{<i})$$

### 3.2 This Is Exact

This is extremely important: the chain rule is **not an approximation**. For any probability distribution, we can exactly factorize it this way without requiring any independence assumptions.

  

## 4. The Ordering Problem

Although the chain rule always works, we have to choose an ordering of the variables. For example, $X_1 \rightarrow X_2 \rightarrow X_3 \rightarrow X_4$ yields one factorization, whereas $X_4 \rightarrow X_3 \rightarrow X_2 \rightarrow X_1$ yields another. Both are mathematically valid.

  

### 4.1 Why Does Ordering Matter?

While the chain rule itself does not care about the ordering, the **modeling difficulty** can depend heavily on it. If data has a natural causal or temporal structure (like a time series $X_1, X_2, \ldots$), it is natural to predict $X_t$ from previous values rather than the reverse. Discovering a good ordering can be a difficult research problem.

  

## 5. Bayesian Networks vs. Neural Autoregressive Models

The chain rule produces conditionals like $p(x_i \mid x_1, \ldots, x_{i-1})$. How do we represent them?

  

- **Bayesian Networks (BNs):** Simplify conditionals using conditional independence assumptions and represent them with Conditional Probability Tables (CPTs). However, for high-dimensional data, these tables grow exponentially and become enormous.
    
      
    
- **Neural Networks:** Instead of a huge lookup table, we use a neural network that receives conditioning variables and outputs the parameters of the next conditional distribution:
    
      
    
    $$(x_1, \ldots, x_{i-1}) \rightarrow \text{Neural Network} \rightarrow p(x_i \mid x_1, \ldots, x_{i-1})$$
    

## 6. Neural Networks as Conditional Models

A neural network can learn shared structure between different configurations, providing a compact functional approximation.

  

### Connection to Classification

This is structurally similar to ordinary supervised learning:

  

- **Binary Classification:** $x \rightarrow \text{model} \rightarrow p(y=1 \mid x)$
    
      
    
- **Autoregressive Model:** $(x_1, \ldots, x_{i-1}) \rightarrow \text{model} \rightarrow p(x_i \mid x_1, \ldots, x_{i-1})$
    
      
    

The difference is that instead of predicting an external label $Y$, we are predicting one component of the data itself using other parts of the same data—hence the term **autoregressive** (regressing on itself).

  

## 7. Logistic Regression as the Simplest Building Block

For a binary variable $Y \in \{0, 1\}$, a simple conditional model is logistic regression:

  

$$p(Y=1 \mid X) = \sigma(w^T x + b)$$

where the sigmoid function is defined as:

  

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

Neural networks increase flexibility by chaining linear transformations and nonlinearities:

  

$$p(Y=1 \mid X) = \sigma(f_\theta(X))$$

## 8. Constructing an Autoregressive Image Model

Consider binarized MNIST, where each image has $28 \times 28 = 784$ pixels, and each pixel $x_i \in \{0, 1\}$. The number of possible images is $2^{784}$, which is astronomically large.

  

Using the chain rule, we turn one impossible high-dimensional problem into **784 conditional prediction problems**:

  

$$p(x_1, \ldots, x_{784}) = \prod_{i=1}^{784} p(x_i \mid x_{<i})$$

### Choosing an Ordering (Raster Scan)

To process images sequentially without a single obvious causal direction, we typically use a **raster scan ordering** (top-left to bottom-right, moving across rows).

  

## 9. Probability Evaluation and Sampling

### Evaluating Probability

Given an image $x$, its probability is computed as:

  

$$p(x) = \prod_{i=1}^{n} p(x_i \mid x_{<i})$$

### Sampling

To generate a sample $x = (x_1, \ldots, x_n)$ step-by-step:

  

1. Sample $x_1 \sim p(x_1)$
    
      
    
2. Sample $x_2 \sim p(x_2 \mid x_1)$
    
      
    
3. Sample $x_3 \sim p(x_3 \mid x_1, x_2)$
    
      
    
    $$\vdots$$
    
    $n$. Sample $x_n \sim p(x_n \mid x_1, \ldots, x_{n-1})$
    
      
    

Unlike generic inference or rejection sampling, autoregressive models give us a direct, straightforward sequential sampling algorithm. However, **generation remains sequential** (later pixels depend on earlier ones, preventing full parallel generation).

  

## 10. Parameter Count and Neural Autoregressive Density Estimation

If each conditional distribution uses independent logistic regression parameters, the total parameter count grows quadratically:

  

$$\sum_{i=1}^{n} (i-1) = \frac{n(n-1)}{2} = \mathcal{O}(n^2)$$

Simple linear logistic models (Fully Visible Sigmoid Belief Network) fail on complex image datasets because they cannot capture intricate pixel dependencies. Replacing them with neural networks creates a **Neural Autoregressive Density Estimator (NADE)**.

  

### Weight Sharing

Instead of learning completely separate neural networks $f_1, f_2, \ldots, f_n$ for each variable, **weight sharing** reuses common parameter matrices. This:

  

1. Drastically reduces parameter count from $\mathcal{O}(n^2)$ down towards $\mathcal{O}(n)$ (depending on hidden dimensions).
    
      
    
2. Reduces overfitting risk.
    
      
    
3. Enables computational reuse and encourages the model to learn shared, useful features.

## 11. Extending Beyond Binary Variables

### Categorical Autoregressive Models

If $x_i \in \{1, 2, \ldots, K\}$ (e.g., pixel intensities $0$ to $255$), the network outputs $K$ raw real numbers (logits) $z_1, \ldots, z_K$, which are converted into a valid categorical probability distribution via the **Softmax function**:

  

$$p_k = \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}}$$

### Continuous Autoregressive Models

For continuous data (speech, measurements), the network outputs the parameters of a continuous probability distribution (such as a Gaussian or a **Mixture of Gaussians**):

  

$$p(x_i \mid x_{<i}) = \sum_{k=1}^{K} \pi_k \mathcal{N}(x_i; \mu_k, \sigma_k^2)$$

## 12. Connection to Autoencoders and Masking

### Why Ordinary Autoencoders Are Not Generative

An autoencoder maps $x \rightarrow h \rightarrow \hat{x}$. While it learns reconstructions, it is not automatically a generative model because we do not know the underlying distribution of the latent space $h$ to sample from it randomly.

  

### The Autoregressive Constraint & Masking

An autoregressive model requires that each prediction $\hat{x}_i$ depends **only** on previous variables $x_1, \ldots, x_{i-1}$, and never on future variables $x_i, x_{i+1}, \ldots$. To enforce this in standard neural network layers during training, we use **Masking**:

  

$$h = (W \odot M)x$$

where $W$ is the weight matrix, $M$ is a binary mask, and $\odot$ is element-wise multiplication.

  

> **Crucial Rule:** Masking **must happen during training**; otherwise, the network learns to cheat by looking at future answers it will not have access to at generation time.
> 
>   

## 13. RNNs as Another Autoregressive Architecture

As sequence length grows, explicitly feeding expanding histories becomes expensive. **Recurrent Neural Networks (RNNs)** solve this by maintaining a hidden state $h_t$ that summarizes history recursively:

  

$$h_{t+1} = f_\theta(h_t, x_{t+1})$$

### Advantages of RNNs:

- **Fixed Parameter Count:** Parameters do not grow with sequence length due to extreme weight sharing.
    
      
    
- **Variable-Length Sequences:** Can process sequences of varying lengths.
    
      
    
- **Flexible Conditionals:** Hidden states can map to Bernoulli, Categorical, or Gaussian mixture outputs.
    
      
    

### Disadvantages of RNNs:

1. **Information Bottleneck:** All historical information must pass through a single vector $h_t$.
    
      
    
2. **Sequential Computation:** Recurrence requires computing $h_1 \rightarrow h_2 \rightarrow h_3 \rightarrow \dots$ sequentially, preventing parallelization across time steps on modern hardware.
    
      
    

## 14. Summary of Model Trade-Offs

|**Model / Architecture**|**Conditional Model**|**Parameter Growth**|**Training Parallelism**|**Generation Nature**|
|---|---|---|---|---|
|**Naive Logistic Autoregressive**|Logistic Regression|$\mathcal{O}(n^2)$|Separate computations|Sequential|
|**Neural Autoregressive**|Neural Networks|Reduced via sharing|Shared computation|Sequential|
|**Masked Autoregressive Network**|Masked Neural Network|Shared|Highly parallelizable|Sequential|
|**RNN Autoregressive**|Recurrent Neural Network|Fixed w.r.t. sequence length|Sequential / unrolled|Sequential|

## 15. Key Vocabulary & Essential Equations

### Essential Equations

- **Chain Rule:**
    
      
    
    $$\prod_{i=1}^{n} p(x_i \mid x_{<i})$$
    
- **Binary Conditional / Sigmoid:**
    
      
    
    $$\sigma(z) = \frac{1}{1 + e^{-z}}$$
    
- **Softmax:**
    
      
    
    $$p_k = \frac{e^{z_k}}{\sum_{j} e^{z_j}}$$
    
- **Autoregressive Log-Likelihood:**
    
      
    
    $$\sum_{i} \log p(x_i \mid x_{<i})$$
    
- **RNN Recurrence & Prediction:**
    
      
    
    $$h_{t+1} = f_\theta(h_t, x_{t+1}), \quad p(x_{t+1} \mid h_t)$$
    

### Key Vocabulary

- **Generative Model:** Represents a probability distribution and generates new samples.
    
      
    
- **IID:** Independent and Identically Distributed.
    
      
    
- **Chain Rule of Probability:** Exact factorization of a joint distribution into conditionals.
    
      
    
- **Autoregressive Model:** Predicts each variable using previously ordered variables from the same data instance.
    
      
    
- **Weight Sharing:** Reusing parameters across multiple tasks/steps.
    
      
    
- **Masking:** Restricting neural network connections to prevent looking into the future.
    
      
    
- **RNN:** Recurrent Neural Network maintaining a hidden state history.
    
      
    

> **Professor's Final Note:** The deepest lesson of this lecture is that autoregressive modeling is fundamentally a clever decomposition strategy. A massive probability distribution that appears impossible to represent directly can be rewritten **exactly** as a sequence of manageable conditional prediction problems. The real modeling challenge then shifts to designing expressive conditional networks while balancing parameter counts, tractability, flexibility, and computational efficiency.

# Q: Make a comparison between the direct method, vs bayes net, logistic regression, and neural network

Each of these four approaches represents a fundamentally different strategy for modeling uncertainty, estimating joint or conditional distributions, and handling the curse of dimensionality.

  

### Core Mechanics & Conceptual Foundations

#### 1. Direct Method (Full Tabular / Empirical Joint Distribution)

- **Core Idea:** Directly model the joint probability distribution $P(X_1, X_2, \dots, X_n)$ by assigning an entry in a lookup table (or counting empirical frequencies) for every possible combination of variable states.
    
      
    
- **Parametric Form:** Unconstrained categorical table. For $n$ binary variables, this requires $2^n - 1$ free parameters.
    
      
    
- **Inductive Bias:** None. It makes zero independence or structural assumptions.
    
      
    
- **Strengths:** Expressively complete. If you have infinite data, it learns the exact true joint distribution without any structural underfitting.
    
      
    
- **Weaknesses:** Intractable for even moderate dimensions ($n > 30$). Suffers catastrophically from the curse of dimensionality and data sparsity—unseen configurations receive zero probability unless explicitly smoothed.
    
      
    

#### 2. Bayesian Networks (Probabilistic Graphical Models)

- **Core Idea:** Factorize the full joint distribution via the probabilistic chain rule, then apply explicit **conditional independence assumptions** encoded as a Directed Acyclic Graph (DAG):
    
      
    
    $$P(X_1, \dots, X_n) = \prod_{i=1}^n P(X_i \mid \text{Parents}(X_i))$$
    
- **Parametric Form:** Local Conditional Probability Tables (CPTs) or localized parametric distributions (e.g., conditional Gaussians) for each node given its parents.
    
      
    
- **Inductive Bias:** High, domain-driven structural bias. Variables are assumed conditionally independent of their non-descendants given their parents (d-separation).
    
      
    
- **Strengths:** Highly interpretable; supports exact/approximate bi-directional probabilistic queries, diagnostic reasoning, and causal modeling; works well with small, expert-structured datasets.
    
      
    
- **Weaknesses:** Structure learning is NP-hard. If nodes have many parents, local CPTs still grow exponentially ($O(2^{\vert{}\text{Parents}\vert{}})$). Exact inference is NP-hard in general graphs.
    
      
    

#### 3. Logistic Regression

- **Core Idea:** A discriminative generalized linear model designed to estimate the conditional distribution $P(Y \mid X)$ rather than the full joint $P(X, Y)$.
    
      
    
- **Parametric Form:** Passes a linear combination of covariates through a sigmoid (or softmax) link function:
    
      
    
    $$P(Y = 1 \mid X) = \sigma(w^T X + b) = \frac{1}{1 + e^{-(w^T X + b)}}$$
    
- **Inductive Bias:** Linear decision boundary in feature space (log-odds are linear in $X$). Assumes features combine additively to affect output odds.
    
      
    
- **Strengths:** Convex optimization (guaranteed global optimum via maximum likelihood/cross-entropy), fast training/inference, highly interpretable feature weights ($w_i$), low risk of overfitting on small samples.
    
      
    
- **Weaknesses:** Cannot learn non-linear decision boundaries or feature interactions without manual feature engineering (kernel tricks, polynomial expansions).
    
      
    

#### 4. Neural Networks (Deep Learning / Multilayer Perceptrons)

- **Core Idea:** Approximate complex mappings by composing alternating affine transformations and non-linear activation functions ($f(x) = \sigma(W_2 \sigma(W_1 X + b_1) + b_2)$).
    
      
    
- **Parametric Form:** Parameterized by weight matrices and bias vectors. Can be discriminative ($P(Y \mid X)$) or generative/autoregressive (e.g., NADE, MADE, RNNs/Transformers factorizing $P(X)$ via the chain rule).
    
      
    
- **Inductive Bias:** Smoothness and hierarchical feature composition (distributed representations). Highly flexible (universal approximators).
    
      
    
- **Strengths:** Automatically discovers hierarchical, non-linear feature representations; scales to millions of inputs (images, audio, text); parameter sharing (e.g., tied weights in autoregressive networks, CNNs) keeps parameter growth linear or sub-linear relative to input size.
    
      
    
- **Weaknesses:** Non-convex optimization (susceptible to local minima, sensitive to hyperparameter tuning); data-hungry; computationally intensive; functions largely as a "black box" lacking direct causal interpretability.
    
      
    

### Comparative Summary

|**Dimension**|**Direct Method (Full Table)**|**Bayesian Network**|**Logistic Regression**|**Neural Network**|
|---|---|---|---|---|
|**Primary Goal**|Joint Modeling $P(X_1, \dots, X_n)$|Joint Modeling $P(X_1, \dots, X_n)$|Conditional Modeling $P(Y \mid X)$|Conditional or Joint (Autoregressive)|
|**Model Type**|Generative (Non-parametric lookup)|Generative (Structured graphical)|Discriminative (Linear parametric)|Discriminative or Generative (Deep functional)|
|**Parameter Scaling**|$O(2^n)$ (Exponential)|$O(n \cdot 2^k)$ where $k = \max \vert{}\text{Parents}\vert{}$|$O(d)$ where $d = \text{features}$|$O(\text{weights})$ (Decoupled from $2^n$ via shared latent layers)|
|**Inference Flexibility**|Any marginal or conditional query|Arbitrary probabilistic queries ($P(A \mid B)$)|Forward prediction $P(Y \mid X)$ only|Forward pass $P(Y \mid X)$ or sequential autoregression|
|**Interpretability**|Trivial (raw cell lookup)|High (graph edges denote dependencies/causality)|High (coefficients show log-odds impact)|Low (distributed black-box representations)|
|**Data Requirement**|Impractically massive for $n > 20$|Low-to-moderate (structural priors reduce data needs)|Low-to-moderate|High (requires large datasets to avoid overfitting)|
|**Handling Non-linearity**|Memorizes all non-linearities explicitly|Captures discrete combinatorial states|Linear only (unless features are manually transformed)|Learns complex non-linear manifolds automatically|

### How They Connect: The Progression of Generative Modeling

To see how these concepts unite, consider modeling a joint distribution $P(X_1, \dots, X_n)$ using the chain rule:

  

1. **Direct Method:** Assumes nothing. Every conditional $P(X_i \mid X_1, \dots, X_{i-1})$ is an exhaustive table requiring exponentially expanding memory.
    
      
    
2. **Bayesian Network:** Tames the table by dropping arrows—assuming $X_i$ is independent of distant predecessors given a small parent set.
    
      
    
3. **Autoregressive Logistic Regression (e.g., FVSBN):** Replaces the discrete tables with logistic regression models for each step $P(X_i \mid X_{<i})$, assuming linear log-odds dependencies on past variables.
    
      
    
4. **Autoregressive Neural Networks (e.g., NADE / MADE / Transformers):** Replaces the linear models with shared, deep neural networks. They retain all historical conditioning without table explosions, using non-linear hidden representations to capture high-order dependencies.
