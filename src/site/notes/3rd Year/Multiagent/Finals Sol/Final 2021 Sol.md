# Q1 - MCQ

1) Intelligent agent is perceiving its environment through …….

- **b. Sensors.**
    

> _Agents use sensors (like cameras or microphones) to perceive their environment and actuators (like robotic arms or wheels) to act upon it._

**2) Agent is called ……….. agent, if it can act or interact without any help from humans**

- **c. an autonomous.**
    

> _Autonomy refers to an agent's ability to operate independently based on its own percepts and learning, without requiring human intervention._

**3) Utility-based agents depend on ………, which maps a state onto a real number which describes the associated degree of “happiness”, “goodness”, “success”.**

- **a. utility function**
    

> _Unlike goal-based agents which just distinguish between "goal" and "non-goal" states, utility-based agents use a utility function to determine exactly how desirable a specific state is._

**4) In a graph theory, an atomic node representation deals with a state as a ……**

- **b. black box with no internal structure**
    

> _In atomic representation (used in standard search algorithms like A_ or BFS), the internal makeup of the state doesn't matter to the algorithm; it is just a distinct node.*

**5) Simple reflex agent does not depend on ……**

- **d. percept history.**
    

> _Simple reflex agents select actions based strictly on the **current** percept, ignoring the rest of the percept history. They do not have memory of past states._

**6) Local search algorithms operate using ……….. and then move to neighbors.**

- **a. a single current node.**
    

> _Algorithms like Hill Climbing operate by evaluating a single current state and moving to a neighboring state, without keeping a full search tree in memory._

7) Hill climbing often gets stuck for the following reasons …….

- **d. Local maxima and ridges.**
    

> _Hill climbing is notoriously vulnerable to getting stuck in local maxima (a peak lower than the global maximum), ridges (a sequence of local maxima), and plateaux (flat areas where neighbors have equal values)._

**8) Constraint satisfaction problems use ……. for each state.**

- **d. a factored representation**
    

> _In CSPs, a state is "factored" into a set of variables, each with its own specific value, rather than being treated as an atomic black box._

**9) A genetic algorithm is a variant of stochastic beam search in which successor states are generated by combining ……. rather than by modifying a single state.**

- **a. two parent states.**
    

> _Genetic algorithms mimic biological reproduction by combining parts of two parent states (crossover) to generate offspring._

**10) A search tree built from a non-cyclic state space has ……**

- **a. limited depth**
    

> _If a state space has no cycles (loops), you cannot revisit the same state infinitely. Therefore, the paths are finite, and the search tree will have a limited (bounded) depth._

# Q2 - T/F


**1) A rational agent should be able to operate autonomously.**

- **True.** To be fully rational in changing environments, an agent needs autonomy to learn and adapt from its own percepts, rather than relying entirely on the prior knowledge programmed by its designer.
    

**2) Goal-based agents do not use knowledge about a goal to guide their actions.**

- **False.** This is the exact opposite of their definition. Goal-based agents specifically use goal information to choose actions that lead to the desired state.
    

**3) Rationality concept for the intelligent agent is equivalent to the perfection.**

- **False.** Rationality means maximizing _expected_ performance based on the agent's current knowledge and percepts. Perfection implies omniscience (knowing the actual outcome of all actions in advance), which is impossible in most real-world environments.
    

**4) Performance of a search algorithm is determined based on four metrics: completeness, optimality, time complexity, and space complexity.**

- **True.** These are the four standard criteria used in artificial intelligence to evaluate and compare search strategies.
    

**5) To be rational agent for most tasks, there is no need to have some degree of autonomy.**

- **False.** A rational agent needs autonomy to handle environments that its designer couldn't fully foresee. Without autonomy, the agent is just a rigid program that will fail if the environment changes.
    

**6) A search (state) space is the set of distinct states, among which we search to find a solution.**

- **True.** The state space encompasses all the possible configurations or states that can be reached from the initial state.
    

**7) For unbounded search tree, the depth-first search algorithm is the most suitable search technique to be used.**

- **False.** Depth-first search (DFS) is a poor choice for unbounded trees because it can get stuck going down an infinite path and never return to explore other branches, making it incomplete.
    

**8) Rational agent possibly become more autonomous with learning.**

- **True.** As an agent learns from its environment, it relies less on its initial, hard-coded programming and becomes more independent (autonomous).
    

**9) Greedy best-first search expands the path that appears to be closest to goal.**

- **True.** It evaluates nodes using a heuristic function $h(n)$ that estimates the cost to the goal, always choosing the node that seems closest.
    

**10) Cyclic state space leads to a bounded search tree.**

- **False.** A cyclic state space (where you can return to a previous state) creates infinite loops, which actually leads to an _unbounded_ (infinite) search tree if not handled properly by the algorithm.
    

**11) Knowledge representation and reasoning enable agents to reach good decisions.**

- **True.** By representing the world formally and using logical inference, knowledge-based agents can deduce the best course of action even in complex scenarios.
    

**12) Breadth-first search technique can not find the optimum solution.**

- **False.** Breadth-first search _is_ optimal if all step costs are equal (e.g., every move costs exactly 1). It is only non-optimal if step costs vary.
    

**13) Simple reflex agents depend only on current percept status.**

- **True.** They map the current percept directly to an action using condition-action rules, completely ignoring the history of past percepts.
    

**14) A* search technique avoids expanding paths that are already expensive.**

- **True.** A* evaluates nodes using $f(n) = g(n) + h(n)$. The $g(n)$ component is the actual cost so far. If a path becomes too expensive, its $f(n)$ value increases, causing A* to switch focus to cheaper, more promising paths.
    

**15) To be rational agent, it is not only to gather information but also to learn as much as possible from what it perceives.**

- **True.** Gathering information (exploration) and learning from it are core requirements for an agent to remain rational and maximize its utility over time in unknown environments.

# Q3 - PEAS

Rationality has four pillars (PEAS: Performance, Environment, Actuators, Sensors) first describe and define these four items briefly.

## Sol

To design an agent, one must specify its "PEAS" description:

- **P - Performance Measure:** The objective criterion for the agent's success (e.g., safety, speed, or profit).
  <br>
- **E - Environment:** The external world or context the agent operates in (e.g., roads, traffic, or a set of students).
  <br>
- **A - Actuators:** The tools the agent uses to change the environment (e.g., steering wheel, screen display, or robotic arm).
  <br>
- **S - Sensors:** The tools the agent uses to perceive the environment (e.g., cameras, GPS, or keyboard).
